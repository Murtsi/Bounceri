# Product

## Register

product

## Users

Operators investigating suspicious online activity, and public demo visitors inspecting sanitised evidence. The existing owner overview remains the default home; session, campaign and metric views retain their existing navigation and appearance. Investigations is an additional opt-in tab.

## Product purpose

Bounceri is an online investigation platform. Clean the traffic is its first module. Cases connect an immutable evidence snapshot to the local detector and separate optional Decision-1 and Featherless assessments. Other modules are explicitly unimplemented.

## Design principles

- Evidence and provenance precede interpretation.
- A synthetic example is always labelled; unknown origin is never called real.
- Missing findings, unavailable services and failed analysis are different states.
- Public visitors inspect records. Administrators control paid review and enforcement outside the public interface.
- Preserve the existing dashboard header, default overview, navigation and visual system. Within the additional tab, use familiar light surfaces, blue selection and amber synthetic or unavailable states, the existing sans family and monospace identifiers.

## Accessibility and inclusion

Use semantic headings and buttons, visible focus, text as well as colour for statuses, reduced motion and a single-column narrow-screen layout. Keep data records readable without requiring horizontal page scrolling.

This scoped context records the owner-approved implementation plan v3 (2026-11-14); it does not add new product scope.
