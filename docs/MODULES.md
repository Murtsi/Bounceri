# Module evidence and capability matrix

Implementation baseline: 14 November 2026. The current capability endpoint in
`src/bouncer/api/investigations.py` advertises only `clean_the_traffic` as
implemented/enabled. The other rows describe planned contracts from
[`modules plan.md`](../modules%20plan.md), not available adapters or measured models.
Core hardening precedes those modules. HTTP campaign detection is part of Clean
the Traffic; Spot the Swarm means a separate social-event pipeline.

Evidence, local interpretation, bounded model questions and final advisory review
are distinct records. The two Featherless roles are not independent votes and
cannot supply labels or activate enforcement. Raw media, social graphs and user
text are not automatically eligible for existing traffic review packets.

Synthetic integration data, measured non-synthetic evidence and genuinely hidden
evaluation must remain separate, with source, split and uncertainty recorded. An
unavailable dataset or capability is not a negative finding. Future capability
activation must depend on the module's actual adapter, analyzer, evaluation,
evidence view and health; a provider flag is insufficient.
