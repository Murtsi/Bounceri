# Team

## People and roles

| Name | Role | Owns | Reachable on |
|---|---|---|---|
| | Lead / integrator | merge queue, `main` health | |
| | Frontend | `src/app`, `src/components` | |
| | Backend / data | `src/server`, `src/db` | |
| | Design / pitch | UI polish, slides, demo script | |
| | Wildcard | integrations, errands, food | |

Nobody owns "everything". If a file has no owner, the integrator owns it.

## Communication

- **Chat:** one channel, one thread per workstream. Decisions land in `docs/DECISIONS.md`, not in chat history.
- **Standup:** 10 minutes, every 4 hours. Format: done / next / blocked / needs-a-decision.
- **Blocked > 15 min?** Say it out loud in the channel with what you tried.

## Working agreement

- The person who merges the breaking change fixes `main` first.
- No one works on the demo flow alone after T-6h.
- Features freeze at T-6h; only polish and bugfixes after.
- One person drives the laptop during the pitch. Everyone else stays quiet.
