Continue Phase 1.8 of the approved modules plan. The previous turn made concrete

## Required behavior

Build one native traffic evaluation path using existing rules, features, campaign
detector and logistic implementation. Load current consented reviews separately
from checksummed synthetic references. Public historical ROBOT labels retain their
own task and cannot enter native maliciousness truth. Never invent missing actor,
run or campaign identities. Reuse the existing whole-component partition builder.

Reserve test groups before fitting. A group used for development cannot later
become a fresh holdout; a held-out actor/run/campaign/native identity cannot be
used for development. Exact preparation replay can reproduce its stored artifact
or report, but cannot restore independence. Claims survive failures and process
restart. All receipts and source bindings use additive checked migrations.

Select only admitted role/context observations before computing campaigns. DNS,
project-site traps, simulator truth and raw private provenance never become score
inputs. Fit preprocessing and model weights only on fit rows; choose thresholds
only on calibration rows. Fit a separate network ablation model. Freeze exact
model/threshold/code/config/feature/dependency bytes before any test score.

Revalidate current consent, annotation revisions, content and source bindings
before using artifacts or cached reports. Serialize against source withdrawal;
source purge scrubs private evaluation payloads and revokes the preparation while
retaining minimal consumption hashes. Original files/exports/backups require
operator reconciliation, as with consent withdrawal and financial archives.

Close legacy publication paths: a synthetic=false source flag, timestamp-only
split or model-version string alone is not verified release evidence. Preserve
development reports and the dashboard, but never let those paths overwrite
production metrics/model or claim an independently withheld attack. A new
publisher must validate frozen receipts and actual evidence gates.
