# Judging

Criteria vary by track; most Junction-style rubrics weight these. Fill the evidence column
the night before submission — that is also your pitch outline.

| Criterion | What judges look for | Our evidence | Status |
|---|---|---|---|
| Impact / relevance | Real user, real pain, credible scale | | |
| Technical execution | Works, non-trivial, sensible architecture | | |
| Design & UX | Looks intentional, flow is obvious in 10 seconds | | |
| Viability | Could exist Monday; business or deployment path | | |
| Presentation | Clear story, confident demo, honest answers | | |
| Track fit | Uses the sponsor's tech in a way they'd showcase | | |
| Originality | Not another ChatGPT wrapper | | |

## Self-check before submitting

- [ ] A stranger can use the core flow without explanation
- [ ] The wow moment happens within 15 seconds of the demo starting
- [ ] Every judge question has a written answer in `PITCH.md`
- [ ] Sponsor API usage is visible, not buried
- [ ] Known limitations stated on the last slide (builds trust)
